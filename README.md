# Проект по основам CSS

Открой в браузере `product-card.html` для карточки на обычном CSS. Открой `pricing.html` для тарифов на Grid. `product-tw.html` показывает карточку на Tailwind и требует интернет для Play CDN.

## Файлы

- `product-card.html` и `style.css` — адаптивная карточка товара.
- `pricing.html` и `pricing.css` — три тарифа с сеткой Grid.
- `product-tw.html` — Tailwind версия с пояснениями классов у пяти элементов.
- `pricing-ref.png` — макет тарифов из учебного урока.
- `images/product.jpg` — фото кофемолки для карточек.

## Сравнение тарифов

В `pricing.css` в начале записаны отличия первой версии от макета и ручные исправления. Изменены фон страницы и размер заголовка. Удалена лишняя строка над заголовком. Уменьшены скругления и отступы карточек. Убран искусственный сдвиг средней карточки.

На мобильном экране тарифы стоят в одной колонке. От 768px включается три колонки Grid. В карточке товара от 768px фото и текст идут рядом.
