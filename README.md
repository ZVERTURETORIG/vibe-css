# Проект по основам CSS

Открой `pricing.html` чтобы увидеть общий сайт. Сверху стоят компактные тарифы. Их блок выровнен по центру и совпадает по ширине с карточкой товара ниже. Центральная карточка остается точно по центру. По нажатию две боковые карточки плавно выезжают слева и справа.

## Файлы

- `pricing.html` и `pricing.css` — страница на чёрном фоне с CSS-анимацией.
- `style.css` — оформление карточки товара и общий чёрный фон.
- `product-card.html` — карточка товара отдельно.
- `product-tw.html` — Tailwind-версия карточки с комментариями к классам пяти элементов.
- `pricing-ref.png` — исходный макет тарифов из учебного урока.
- `images/product.jpg` — фото кофемолки для карточек.

На экране шире 768px нажми на центральный тариф. Он останется по центру. Два других плавно выедут по сторонам. На телефоне они появятся столбиком. Фон страницы чёрный. Градиент есть только на центральном тарифе. Взаимодействие сделано без JavaScript через CSS checkbox.

## Сравнение тарифов

В начале `pricing.css` записаны отличия первой версии от макета. Были исправлены фон и размер заголовка. Удалена лишняя строка над заголовком. Уменьшены скругления и отступы карточек. Убран искусственный сдвиг средней карточки.

Карточка товара внизу использует адаптивную раскладку. От 768px фото и текст стоят рядом. На узком экране они идут столбиком.
